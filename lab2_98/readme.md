# ThreadLab - Многопоточная обработка массива(98 стандарт)

Проект демонстрирует параллельные вычисления с использованием pthreads. Программа:
1. Читает массив чисел от пользователя
2. В двух потоках одновременно:
   - Находит мин/макс значения
   - Вычисляет среднее арифметическое
3. Заменяет все мин/макс элементы на среднее значение

## Структура
- **DataManager** - управление данными
- **DataProcessor** - вычислительные операции
- **ThreadController** - работа с потоками
- **ThreadManager** - основной координатор
