# Sync - Межпроцессное взаимодействие через разделяемую память

Проект реализует систему обмена сообщениями между несколькими процессами через разделяемую память.

## Архитектура
- **Receiver** - главный процесс, управляет буфером сообщений
- **Sender** - процессы-отправители, пишут сообщения в общий буфер
- **Разделяемая память** - общий буфер для передачи сообщений между процессами

## Основные компоненты
- **common.h** - общие структуры данных (структуры Msg и SharedData)
- **receiver.cpp** - процесс-получатель, читает и управляет сообщениями
- **sender.cpp** - процессы-отправители, пишут сообщения в буфер
- **test_main.cpp** - модульные тесты структур данных

## Принцип работы
1. **Receiver** создаёт общий буфер в разделяемой памяти
2. **Sender** процессы подключаются к этому буферу
3. **Sender** пишут сообщения в циклический буфер
4. **Receiver** читает сообщения в порядке поступления
5. Буфер работает по принципу FIFO с защитой от переполнения
