# EmployeeSystem - Система управления сотрудниками с блокировками

Клиент-серверная система для управления записями сотрудников с поддержкой конкурентного доступа и блокировок.

## Архитектура
- **Сервер** - центральный процесс, управляет данными и блокировками
- **Клиенты** - процессы, взаимодействующие с сервером через FIFO
- **Разделяемая память** - обмен данными через именованные каналы

## Основные компоненты
- **server** - главный сервер, координирует работу клиентов
- **client** - клиентские приложения для чтения/изменения данных
- **FileManager** - управление файлом с данными сотрудников
- **LockManager** - система блокировок для конкурентного доступа
- **FIFOManager** - работа с именованными каналами (FIFO)

## Принцип работы
1. Сервер создает FIFO и инициализирует файл с данными
2. Клиенты подключаются к серверу через именованные каналы
3. Клиенты могут:
   - Читать данные сотрудников (разделяемая блокировка)
   - Изменять данные (эксклюзивная блокировка)
   - Освобождать блокировки
4. Сервер управляет конкурентным доступом через систему блокировок
