# Lab3_Synchronization - Управление потоками с синхронизацией

Проект реализует многопоточное взаимодействие с использованием мьютексов и событий для безопасной работы с общим массивом.

## Основная логика
- Создание N "маркерных" потоков, которые помечают элементы массива
- Каждый поток помечает нулевые элементы своим ID
- При невозможности пометить элемент поток приостанавливается
- Пользователь выбирает, какой поток завершить
- При завершении потока его помеченные элементы обнуляются
- Процесс продолжается, пока есть активные потоки

## Структура проекта
- **ArrayManager** - управление массивом, проверка границ
- **PlatformSync** - кросс-платформенные примитивы синхронизации (мьютексы, события, потоки)
- **ThreadManager** - создание и управление потоками, координация работы
