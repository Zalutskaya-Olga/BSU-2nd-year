# BSU-2nd-year

# Университетские лабораторные работы по системному программированию

Коллекция лабораторных работ, демонстрирующих различные аспекты системного программирования на C++ и Python.

##  Структура проектов

###  **Lab1 - ThreadLab**
Многопоточная обработка массива с использованием pthreads. Поиск мин/макс значений и среднего арифметического в параллельных потоках.

###  **Lab3 - Синхронизация потоков**
Управление потоками с мьютексами и событиями. Потоки-"маркеры" работают с общим массивом с системой приостановки и возобновления.

###  **Lab4 - Межпроцессное взаимодействие**
Клиент-серверная система обмена сообщениями через разделяемую память (FIFO). Множество процессов-отправителей пишут в общий буфер.

###  **Lab5 - Employee System**
Клиент-серверная система управления сотрудниками с блокировками. Реализация read/write блокировок через именованные каналы.

###  **Kollokvium_Zalutskaya - Hello Kitty Todo API**
Веб-приложение на FastAPI для управления задачами в стиле Hello Kitty. Полный стек: REST API, SQLite, Redis, Docker, Prometheus.

##  Технологический стек

- **Языки**: C++ (11/17), Python 3
- **Многопоточность**: pthreads, мьютексы, условные переменные
- **Межпроцессное взаимодействие**: FIFO, разделяемая память
- **Базы данных**: SQLite, Redis
- **Веб**: FastAPI, Jinja2, Prometheus
- **Контейнеризация**: Docker, Docker Compose
- **Тестирование**: Google Test, модульные тесты

##  Лицензия

Учебные материалы для изучения системного программирования.

## Цель: Освоить фундаментальные концепции системного программирования через практические реализации разного уровня сложности.
